# EnergiaViva

Sistema web em React + TypeScript para gestão de desperdício e potenciais de economia de energia em empresas.

## Funcionalidades

- Dashboard executivo com indicadores de consumo, custo e desperdício
- Comparativo por período e unidade
- Acompanhamento de oportunidades de eficiência com prioridade e status
- Alertas operacionais e tabela de performance por setor
- Persistência local em navegador para simular ações do usuário

## Como executar

1. Instale as dependências:
   npm install
2. Inicie o servidor de desenvolvimento:
   npm run dev
3. Acesse a URL indicada no terminal (normalmente http://localhost:5173)

## Build de produção

npm run build

## Observações

Os dados são demonstrativos e podem ser adaptados para o cenário real da empresa.
